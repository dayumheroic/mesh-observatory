# Security and privacy

This is a research preview, not a security-certified product. Report suspected vulnerabilities privately to ststeinhoff@gmail.com with a minimal synthetic reproducer. Do not send live credentials or household data. No response-time guarantee is offered.

Local captures and application configuration remain outside Git. Export aliases and timestamps can still reveal activity; do not treat pseudonymization as anonymization. Cloud publication is optional and requires its own private configuration and authenticated access.

The collector accepts an explicit private IPv4 target and pinned router certificate. A certificate mismatch requires owner review. Never replace a pin merely to make a failed request succeed.

Keep installations on loopback as documented. Do not expose the native bridge directly to a public network. This extraction does not deploy a service, alter a router or transfer private telemetry.
